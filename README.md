# Developer Portfolio Generator (Markdown to Website)

## Run
1. Extract the folder and open `index.html` in a modern browser.
2. Edit the Markdown in the left panel. The right panel updates live.
3. Choose Clean Light, Midnight or Fresh Mint.
4. Click **Download website HTML** to save a standalone portfolio page.

## Features
- Markdown headings, paragraphs, lists, emphasis, inline code and links
- Live preview in a sandboxed iframe
- Three switchable visual themes
- Export as a standalone HTML file

## Technology
HTML5, CSS3 and vanilla JavaScript. Markdown conversion is a small local parser for the syntax documented in the interface; it is not a full CommonMark implementation. GitHub Pages deployment can be done by uploading the downloaded HTML file to a repository and enabling Pages in repository settings.
